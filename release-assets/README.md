# Pacchetti pronti

- `VibraVidPanel-1.3.1.0-Installazione.zip`: per l'installazione manuale; contiene
  la cartella da copiare, la guida, le licenze e i checksum.
- `VibraVidPanel-1.3.1.0.zip`: formato per il catalogo Jellyfin, con la DLL
  direttamente nella radice dello ZIP.
- `SHA256SUMS.txt`: checksum dei due pacchetti.

I file del plugin sono compilati dai sorgenti della versione 1.3.1.0 inclusi
nel repository. I pacchetti contengono soltanto plugin e documentazione.

Per rendere disponibile il feed del catalogo con gli URL del tuo repository,
segui [la guida alla pubblicazione](../docs/PUBBLICAZIONE.md). Questi pacchetti
precompilati non includono un manifest con un account GitHub fittizio.
