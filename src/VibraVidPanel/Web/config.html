VibraVid Panel

La GUI si apre dentro Jellyfin. È il server Jellyfin a collegarsi al container: dal telefono serve soltanto l’accesso a Jellyfin.

Inserisci l’URL raggiungibile dal server Jellyfin, completo di http:// o https:// e porta. Può essere un indirizzo LAN. Le cartelle di download restano quelle già configurate in VibraVid.

La GUI resta quella del tuo container esistente. Gli utenti condividono le funzioni e i permessi già disponibili in VibraVid.
